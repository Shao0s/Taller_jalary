# Jalyry - Sistema de Gestión de Taller Mecánico

## Descripción

Jalyry es una aplicación web desarrollada para la gestión de un taller mecánico. Permite a los clientes registrarse, iniciar sesión, gestionar sus vehículos, solicitar citas y consultar su historial. Además, cuenta con un panel de administración para gestionar la información del sistema.

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* Firebase Authentication
* Firebase Firestore
* GitHub Pages

## Funcionalidades

### Clientes

* Registro de usuarios.
* Inicio de sesión.
* Registro de vehículos.
* Solicitud de citas.
* Consulta de historial.
* Cierre de sesión.

### Administrador

* Inicio de sesión como administrador.
* Gestión de citas.
* Consulta de historial.
* Acceso al panel administrativo.

## Instalación y Ejecución

### Opción 1: Sitio desplegado

Acceder directamente desde GitHub Pages:

https://shao0s.github.io/Taller_jalary/

### Opción 2: Ejecución local

1. Clonar el repositorio.
2. Abrir el proyecto con un servidor local.
3. Acceder desde el navegador.

Ejemplo:

```bash
python -m http.server 3000
```

Luego abrir:

```text
http://localhost:3000
```
